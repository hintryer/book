# 开源阅读APP书源配置说明

## 文件说明

- `book.json` - 小说数据文件
- `book_source.json` - 开源阅读APP书源配置文件

## 使用方法

### 1. 导入书源

打开**阅读APP** → 点击右下角**我的** → 选择**书源管理** → 点击右上角**导入** → 选择**本地导入**，然后选择 `book_source.json` 文件。

### 2. 启用书源

在书源列表中找到"本地JSON书源"，确保开关处于启用状态。

### 3. 搜索书籍

返回首页 → 点击**搜索** → 输入"测试小说"或"作者名" → 在搜索结果中选择书籍即可阅读。

## 书源配置说明

这个书源使用 JSONPath 规则解析本地 JSON 文件：

- **搜索规则**: 从 `$.book` 提取书籍信息
- **书籍信息规则**: 提取标题、作者、封面、简介
- **目录规则**: 从 `$.book.chapters[*]` 遍历所有章节
- **正文规则**: 从 `$.content[*]` 数组中提取段落并用换行符连接

## 自定义修改

如果你想修改书源以适配其他 JSON 格式：

1. **修改搜索规则** (`ruleSearch`): 调整 JSONPath 表达式匹配你的数据结构
2. **修改目录规则** (`ruleToc`): 指定章节列表的路径
3. **修改正文规则** (`ruleContent`): 指定正文内容的提取方式

### JSONPath 语法示例

- `$.book.title` - 获取 book 对象的 title 字段
- `$.chapters[*]` - 获取 chapters 数组的所有元素
- `$.content[*]@join('\n')` - 获取 content 数组并用换行符连接

## 注意事项

⚠️ 这个书源配置使用 `local://` 协议，适用于本地 JSON 文件。如果你的数据来自网络 API，需要将 URL 改为实际的 HTTP/HTTPS 地址。

## 兼容性

适用于以下开源阅读APP：

- **阅读** (legado) - 支持
- **阅读3.0** - 支持
- 其他支持自定义书源的阅读APP

## 数据结构示例

参考 `book.json` 中的数据格式：

```json
{
  "book": {
    "title": "小说标题",
    "author": "作者",
    "cover": "封面图片URL",
    "intro": "简介",
    "chapters": [
      {
        "chapterTitle": "章节标题",
        "chapterUrl": "章节URL",
        "content": ["段落1", "段落2", "..."]
      }
    ]
  }
}
```
